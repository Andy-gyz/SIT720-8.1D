Sydney Housing Price Prediction 

The single working dataset contains 102 priced sold listings across Chatswood, Parramatta and Penrith: 35, 35 and 32 respectively. Two ambiguous or special transactions were excluded before modelling.

Install the dependencies, open the notebook from this project folder and choose Restart Kernel and Run All. To use the app, run `demo.launch()` after the app-definition cell and open the printed local URL.

CSV dates use YYYY-MM-DD, prices use AUD and areas use square metres. Blank is not zero. Area fields retain different meanings. The assistant transcribed the observations from public pages; student checks remain pending in the data. Source URLs support those checks.
